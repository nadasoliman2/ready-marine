Update business pickup location

put
http://app.bosta.co/api/v2
/pickup-locations/{id}

Request

Security: Bearer Auth
Security: API Key

Path Parameters

id
string
required

Pickup location ID

Body

locationName
string
required

The name of the business pickup location

Example:
21 Abdelsalam St
contacts
array[object]
required

contact persons for this location

firstName
string
required

Contact person's first name

Example:
Mohamed
lastName
string
required

Contact person's last name

Example:
Magdy
phone
string
required

Contact phone number

Example:
01063535663
isDefault
boolean

Indicates if this contact is the default contact

Example:
true
address
object
required

The pickup location address. For guidance on how to get the districtId and format a Bosta address, see the Bosta address guide: https://docs.bosta.co/docs/how-to/format-bosta-address

districtId
string
required

District identifier within the zone

Example:
District456
firstLine
string
required

First address line (street name/major address detail)

Example:
21 Abdelsalam St
secondLine
string

Additional address line (e.g., building entrance, street direction)

Example:
Near City Mall
floor
string

Floor number of the address

Example:
3
apartment
string

Apartment number

Example:
305
buildingNumber
string

Building number

Example:
21
